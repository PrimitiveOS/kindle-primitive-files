# Install Files

Open **Store** from your existing Primitive Launcher. Find **Files** under Utilities and tap **Get**.
After installation, open **Files** from the Launcher grid.

For local testing, use the ARMHF release package on a supported Kindle running PrimitiveOS. Choose
the Store version for normal installation and updates. Install Viewer separately to open PDFs, JPEGs,
and PNGs from Files. If you already use KOReader, you can also open its supported formats from the
item menu. Closing a reader returns to Launcher.
